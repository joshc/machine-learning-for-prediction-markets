    Review scope and interpretation¶

    The review process separates technical correctness from whole-manuscript editing. It is an internal quality-control process, not academic peer review, a legal opinion, or certification that a strategy is profitable.

    Technical review should inspect derivations, empirical claims, source support, information availability, accounting, statistical selection, execution assumptions, and the boundary between hypothetical, synthetic, historical, and actual results. It should compare the executable examples to the text rather than treating successful execution as evidence that the underlying model is true.

    Editorial review should read the complete ordered manuscript and its supporting notation, glossary, references, and exercise material. It should address contradictions between chapters, missing prerequisites, terminology changes, duplicated explanations, unsupported novelty claims, confusing examples, and overconfident language about profit.

    Review records must say what was actually read, what was checked, which issues were found, how they were resolved, and which limitations remain. A generated word count or source inventory is not evidence that an editor read those words or inspected those sources.

    The manuscript inventory command uses standard-library Python from the trading repository root:

    python book\scripts\manuscript_inventory.py

    Its only purpose is to make coverage explicit and help readers locate the files. It does not score the quality of the writing or certify the statistical evidence.

    The manuscript checks and companion checks are now separate. From the trading repository root:

    python book\scripts\assemble_claims.py --check
python -m unittest discover -s book\tests -q

    Run educational Python examples, code tests, and the NOAA study from book\companion, using that project's .venv; see the companion README. Historical review counts and commands describe the pre-relocation work and are not new validation claims for the directory move.
